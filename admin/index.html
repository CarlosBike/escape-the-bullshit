    If the screen above does not come up

    Use the built-in local editor instead. It needs no internet connection, no GitHub account and no sign-in. It writes straight into your content files and rebuilds the site for you.

    Open the local editor

    First time here

    1. Press Log in with GitHub. Approve access to the one repository and you are taken back here.
    2. Choose Pages or Topics from the list on the left.
    3. Pick a topic, change a sentence, and press Save.
    4. Sveltia commits the change to GitHub for you. Run npm run sync on your own computer to pull it down and rebuild.
    5. Reload the site in your browser to see it.

    If sign-in does not work

    Check that admin/config.yml contains name: github, repo: CarlosBike/escape-the-bullshit and branch: main, and that it has no base_url line. A base_url line makes the screen ask GitHub for the wrong address and GitHub answers with a 404 Not Found error.

    If the repository is private, GitHub hides it behind the same 404 unless the sign-in has permission for that one repository. The quickest check is to make the repository public for a moment (Settings → General → Danger Zone → Change visibility) and try again. You can make it private afterwards.

    If the screen asks for a token instead of offering a GitHub button, create a fine-grained token in GitHub under Settings → Developer settings → Personal access tokens, limited to this one repository, with Contents: read and write. GitHub shows the token only once.

    Adding something new

    Press New at the top of the list. For Topics you get a labelled box for each section of an article; for Pages you get a title, a menu label and one large box for the page text. Fill it in and save — no other file needs changing.

    The address of a new page or article comes from the file name, which the editing screen creates from the title. Renaming the file later changes the address, so leave it alone once you have shared a link.

    About the wording

    Several pages cover health, dental and financial matters. They say plainly when a question needs a doctor, a dentist or a qualified adviser rather than a website. Please keep those notes in place when you rewrite a page — they matter for the reader and for the site's credibility.
